## 搬瓦工官网打不开？按顺序排查

排查顺序如下：

1. **先换备用域名**：把 `bandwagonhost.com` 替换成 `bwh81.net`，直接回车。90% 的情况这一步就解决了。
2. **刷新本地 DNS 缓存**：Windows 打开命令提示符，运行 `ipconfig /flushdns`；Mac 在终端运行 `sudo dscacheutil -flushcache`。
3. **换一个 DNS 服务器**：临时把设备 DNS 改成 `8.8.8.8`（Google）或者 `1.1.1.1`（Cloudflare），再试试看。
4. **换网络环境**：手机流量和宽带有时候表现不同，试着切换一下。
5. **晚高峰问题**：搬瓦工官网偶尔在晚高峰时段访问不稳定，稍等几分钟再试有时候就好了。
